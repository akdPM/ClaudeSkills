## 11. Which sources for which job

| Job | Start with | Then |
|---|---|---|
| Dashboard, builder or settings screen | Refero | CollectUI, UI Wiki, 21st.dev |
| Onboarding or any multi-step flow | Refero (flows) | Recent, CollectUI |
| Landing page as a whole | Godly, Siteinspire | Awwwards, Refs.Gallery |
| One landing section (hero, pricing, footer) | Curated, Sections.wtf, Unsection | Supahero, Headers Club, Footer.design |
| Portfolio or case-study page | Behance, Siteinspire | Awwwards, Godly |
| Mobile app screen | Refero (iOS), Recent | Xcode Resources |
| Visual direction, theme or mood | Cosmos, Brand Archive | Pinterest, Abduzeedo, Dark.design |
| Type pairing | FontBrief, Fontshare | Free Faces, Velvetyne |
| Motion and micro-interaction | Refs.Gallery, React Bits | Motion-Primitives, Skiper UI, Fancy Components |
| Illustration or empty-state art | Blush, Open Doodles | Humaaans, Fresh Folk, Graphic Sauce |
| Icons | LsIcon, Octicons | Noun Project |
| Backgrounds and decoration | The Pattern Library, Topography Generator | Pryzm, React Bits |
| Presenting screens in mockups | Mockuuups Studio | The Stocks |
